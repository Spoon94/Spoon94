# Spoon

**AI Navigator** · learning AI, specializing in **AI Harness**

I build tooling for **AI coding agents** — skill collections, CLI utilities, and knowledge systems that make day-to-day work with agents faster.

---

### 📦 [skill-vault](https://github.com/Spoon94/skill-vault)

**63** self-contained **[Agent Skills](https://agentskills.io/specification)** for Claude Code, Codex CLI, Copilot CLI, Gemini CLI and OpenCode — grouped by scenario: explain & draw · dev workflow · retrieval · notes & memory · ops & integrations · docs & design.

### 🦦 [cli-zoo](https://github.com/Spoon94/cli-zoo)

A small zoo of shell tools for AI-coding workflows, symlink-installed to `$PREFIX`.

- **otter** — tmux session with your AI CLI, yazi, nvim and lazygit in one layout
- **wren** — two-line Dracula statusline for Claude Code, pi, Qoder CLI and opencode
