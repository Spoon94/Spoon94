### 🦦 [cli-zoo](https://github.com/Spoon94/cli-zoo)

A small zoo of shell tools for AI-coding workflows. One script per tool, symlink-installed to `$PREFIX`.

| Tool | What it does |
| --- | --- |
| **otter** | Spins up a tmux session with your AI CLI, yazi, nvim and lazygit in one layout — one command into a working setup. |
| **wren** | Two-line Dracula statusline (tokens, cache hit rate, compaction count, context usage) installed into both Claude Code and pi. |
